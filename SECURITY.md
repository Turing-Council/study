# Security policy

Turing Study holds student accounts, uploads and practice history, so we take reports seriously.

## Reporting a vulnerability

**Don't open a public issue.** Report privately through GitHub: go to the [Security tab](https://github.com/Turing-Council/study/security) and click **Report a vulnerability**.

Please include what you found, how to reproduce it, and what an attacker could do with it. We aim to reply within 7 days. We're students, so response can be slower during exam periods.

## Copyright and takedown requests

If material on the platform infringes your rights (for example an exam paper or someone's notes), use the same private form and mark it **Takedown**. We aim to act within 24 hours.

## Scope

- In scope: this repository and the deployed Turing Study site.
- Out of scope: DTU's own systems (DTU sign-in, kurser.dtu.dk). Report those to DTU.
- Please don't access other users' data, run load or denial-of-service tests, or use automated scanners against production.

## Supported versions

Only the latest deployed version is supported.

## Personal data

If your report involves personal data of students, tell us in the report so we can handle it under GDPR.
